Freebuild

Der Freebuild-Modus bietet dir kreative Plot-Grundstücke, auf denen du ohne Überlebenszwang bauen kannst! Nutze WorldEdit, verschiedene Heads aus der Head Database, und alle verfügbaren Blöcke, um deine kreativen Ideen umzusetzen.

✨ Features

  • Plot-System mit verschiedenen Größen
  • Kreativ-ähnliche Bau-Erfahrung im Survival-Kontext
  • WorldEdit für fortgeschrittene Builder (höhere Ränge)
  • Head Database mit tausenden Custom Heads (/hdb)
  • Plot-Biome ändern (höhere Ränge)
  • Plot-Musik & Wetter einstellen
  • Spieler zu deinem Plot einladen
  • Plot-Rating & Showcase-System

🎯 Spielziel

  • Baue beeindruckende Kreationen auf deinen Plots
  • Nimm an Bau-Wettbewerben teil
  • Zeige deine Builds der Community
  • Sammle Ratings und Feedback von anderen Spielern
  • Nutze mehrere Plots für große Projekte (höhere Ränge)
  • Werde zum besten Builder auf dem Server

🛠️ Wichtige Befehle

  • /plot auto - Claime automatisch ein freies Plot
  • /plot home - Teleportiere zu deinem Plot
  • /plot add <Spieler> - Füge Spieler zu deinem Plot hinzu
  • /plot trust <Spieler> - Gib Spieler Build-Rechte
  • /plot deny <Spieler> - Sperre Spieler von deinem Plot
  • /plot clear - Lösche dein Plot (Vorsicht!)
  • /plot biome <Biom> - Ändere das Biom (ab Macher-Rang)
  • /plot music - Setze Hintergrundmusik (ab Bratan-Rang)
  • /hdb - Öffne die Head Database (ab Maschine-Rang)
  • /plot visit <Spieler> - Besuche andere Plots

📏 Plot-Größen nach Rang

  • NPC-Rang: 1 Plot (Standard-Größe)
  • Hustler-Rang: 2 Plots
  • Bre-Rang: 3 Plots
  • Maschine-Rang: 4 Plots
  • Main Character: 5 Plots
  • Rolex (Geld): 6 Plots
  • Oligarch (Geld): 7 Plots
  • Endgegner (Geld): 10 Plots
  • Admin sein Vater (Geld): 50 Plots

💡 Bau-Tipps

  • Plane dein Build vorher – nutze ggf. Skizzen oder Referenzen
  • Nutze verschiedene Texturen für mehr Detail
  • Die Head Database bietet tausende Deko-Möglichkeiten
  • Experimentiere mit verschiedenen Biomen für Atmosphäre
  • Lade Freunde ein, um gemeinsam zu bauen
  • WorldEdit (höhere Ränge) beschleunigt große Projekte massiv
  • Besuche andere Plots für Inspiration
  • Nimm an Bau-Events teil für Belohnungen

🏆 Plot-Rating System

  • Andere Spieler können dein Plot bewerten
  • Gute Ratings erhöhen deine Builder-Reputation
  • Top-bewertete Plots werden featured
  • Nutze /plot rate um Plots zu bewerten

🚀 Schnellstart

  1. Teleportiere mit /warp freebuild zum Freebuild
  2. Claime dein erstes Plot mit /plot auto
  3. Sammle Baumaterialien (farme oder kaufe im Shop)
  4. Beginne mit dem Bauen deiner Idee!
  5. Nutze /hdb für Custom Heads (ab Maschine-Rang)
  6. Lade Freunde ein mit /plot add [Spieler]
  7. Zeige dein fertiges Build der Community!
💡 Tipp:

Kombiniere Freebuild mit anderen Modi! Farme Ressourcen im Tycoon, verdiene Geld und kaufe höhere Ränge für mehr Plots und bessere Build-Tools.
